# Giuliana's Website 🌈🦄

A fun, colorful website made for Giuliana (age 6), in pink, blue, and purple.

## Pages
- **Home** — a big happy welcome.
- **My Art** — Giuliana's art shop! Five real drawings for sale, each tappable to open big and zoom in.
- **My Favorite Things** — all the stuff she loves.
- **About Me** — fun facts.

## Fun features
- A winged unicorn that flies around and chases your cursor 🦄
- Colorful sprinkles falling down the page
- A unicorn-face background wallpaper
- Big, friendly buttons
- Tap-to-zoom art viewer (pinch / scroll to zoom, drag to move)
- A friendly "How to buy" pop-up on each artwork

## Running it locally
It's a plain static site — no build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4321
```

Then visit http://localhost:4321

## Files
- `index.html`, `art.html`, `favorites.html`, `about.html` — the four pages
- `styles.css` — all the styling
- `unicorn.js` — the flying unicorn + falling sprinkles
- `images/art-1.jpg` … `art-5.jpg` — the artwork photos
